Model endpoints

Each endpoint is either local (a llama-server the harness spawns) or openai (any external OpenAI-compatible backend: another llama-server already running, Ollama, a hosted API). An external endpoint takes a base URL, an optional API key, and one or more model ids.

[
  {
    "id": "local",
    "kind": "local",
    "name": "Local llama-server",
    "binary": "C:\\path\\llama-server.exe",
    "model_path": "C:\\models\\model.gguf",
    "ctx_size": 32768,
    "gpu_layers": -1,
    "n_parallel": 1,
    "port": 8081,
    "cache_type_k": "q8_0",
    "cache_type_v": "q8_0"
  },
  {
    "id": "ollama",
    "kind": "openai",
    "name": "Ollama",
    "base_url": "http://localhost:11434/v1",
    "api_key": "",
    "models": [
      {"id": "llama3.2", "name": "Llama 3.2", "ctx_size": 32768}
    ]
  }
]

The active endpoint's kind decides whether the harness spawns llama-server. Switching between a local and an external backend requires a harness restart; switching between two external endpoints applies live.
